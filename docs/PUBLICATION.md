# Publication decision

The v0.6.4 artifact adds leak-free backward BTC windows to the verified v0.6.3
release and is mechanically validated for publication under the mixed-source,
non-commercial conditions documented in [RIGHTS.md](RIGHTS.md) and in the
release archive's `data/rights_matrix/unknown.parquet` table.

Forward and backward returns are observed price moves, not causal-effect
estimates. GitHub, Hugging Face, or Kaggle platform labels do not replace
source-specific terms.
